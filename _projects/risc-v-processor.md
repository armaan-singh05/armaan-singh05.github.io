## Overview

I designed a custom RISC-V processor core, building and refining several iterations of its
arithmetic, logic and shift units, and documented the architectural decisions in a set of technical reports.

## What I did

- Built multiple iterations of the arithmetic, logical and shifter hardware modules for a custom RISC-V core.
- Wrote technical reports on the microarchitectural choices and functional specifications.
- Automated functional and timing verification of the custom ALU blocks using TCL scripts in ModelSim.
- Compared Cyclone IV and Arria II FPGA targets for power, resource use and execution speed.
